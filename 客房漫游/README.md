# 客房三维漫游

在本目录运行 `node server.mjs`，打开 http://127.0.0.1:5186 。

门在南侧（图下侧）靠左。门顶与四面墙齐平，展示高度 2.72 米。白色高书柜从入口门扇打开净空外沿左墙一直铺到窗墙；床沿右墙向左加宽。房间与家具尺寸仅为展示估算，非实测尺寸。

- 拖动旋转、滚轮缩放；点击物品显示说明。
- 空间全景、俯瞰布局、走进房间三种视角。
- 可开关门、切换日夜灯光、剖开外墙、保存画面。
- 小物件由 Hyper3D Gen-2.5-High 独立生成，模型与来源记录见 dist/models/manifest.json。

房间墙体采用浅蓝硅藻泥的哑光细颗粒效果，定制柜体和整墙书柜使用程序几何建模；11 件小物件由 Hyper3D Gen-2.5-High 独立生成并拼接。照片提供外观参考，生成模型不是实物扫描。
