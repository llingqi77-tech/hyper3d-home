# 餐厅 · 第一人称漫游

入口：http://127.0.0.1:8765/ 。如果地址无法连接，双击本目录的 `启动预览.cmd`，再打开入口。启动器使用本机现有 Python 运行时在后台启动服务，仅监听 127.0.0.1。当前本地服务根目录是本文件所在目录。页面需通过 HTTP 服务打开，Three.js 0.164.1 模块从 unpkg 加载，需要联网；家具 GLB 从本地 assets 加载。

## 操作

1. 等待加载完成，点击「进入参观」。
2. 按住鼠标左键拖动或触屏滑动，环顾四周。
3. W/A/S/D、方向键或右下角长按按钮移动。
4. R 或「返回入口」复位；Esc 暂停；问号显示操作说明。

视高 1.6 米。家具和墙体具有平面碰撞限制，摄像机不会飞行。无物件标签、灯光控制或选择面板。基础固定照明只用于显示材质。

## 布局依据

以最新俯视示意图为布局依据：图下方为入口侧，上方时钟后方为客厅延伸方向。大门位于入口侧右端；餐边柜旋转 90°，位于左下角，宽背面沿入口侧墙，左端抵左墙；鞋柜与餐边柜右端相接。餐桌靠左墙中段，假窗在它上方；油画位于对面右墙。时钟移至左前方，后方门洞通往客厅方向。第一人称起点位于右下方大门内侧，朝餐桌和客厅方向看。尺寸按项目《户型图》调整：纵深取图中 325 cm，即 3.25 m；入口左侧 240 cm 墙段，加约 90 cm 入口通道，场景总宽约 3.30 m。240 与 325 为图示标注，90 cm 通道宽度为估算。餐桌改为 1.55 × 0.90 m，餐边柜宽 1.50 m，鞋柜宽 0.90 m；柜子均匀缩放。桌边到柜前约 0.76 m，五把椅子向桌边收拢。时钟后方的客厅占位纵深取图中 375 cm。

## 餐桌处理与限制

现有餐桌模型都混有残缺椅子，因此桌架、四条桌腿、格纹桌布和藏蓝裙边由 Three.js 重建。保留 `餐桌_独立彩色.glb` 内部可分离的桌面摆件几何，裁去外部椅子。没有把旧餐桌椅组合直接放入场景，也没有创建新的 Hyper3D 生成任务。桌面摆件仍保留生成资产原有的简化细节。

所有独立家具按单一比例缩放，不再分别拉伸 XYZ。墙体、顶面、踢脚线、陶土角花瓷砖由 Three.js 创建。瓷砖与布纹为程序纹理。`index.previous.html` 保存旧页面，`asset-review.html` 是资产外观对照页。源码为 `index.html`、`style.css`、`room.js`。





## 尺寸维护
room.js 中 ROOM、LEFT、RIGHT、ENTRY、FRONT 统一控制房间尺寸及贴墙位置。缩短前源码保存在 room.before-floorplan.js。当前版本 floorplan-compact-6。


## 钟面与假窗（clock-window-7）
钟面朝向餐边柜中心，由模型实际位置计算水平朝向。假窗宽高等比例缩小 20%，面积减少约 36%；保留原中心高度、餐桌上方位置及贴墙关系。
