# 餐厅与客厅 · 3D 导览

请在仓库根目录运行 `python3 -m http.server 8765 --bind 127.0.0.1`，再打开 <http://127.0.0.1:8765/>；Windows 可使用本目录的 `启动预览.cmd`。必须从仓库根目录提供网页，以便加载根目录中的实景照片。Three.js 0.164.1 模块从 unpkg 加载，首次打开需要联网。

## 操作

1. 等待加载完成，点击「从门外进入」，自动穿过餐厅与拱门。
2. 按住鼠标左键拖动或触屏滑动，环顾四周。
3. 点击地面自动行走，或使用 W/A/S/D、方向键、右下角按钮移动。
4. 点击地面浅金色圆点快速到达餐厅或客厅角落；俯瞰时点击房间地面会跳到最近的角落。
5. R 返回门外；Esc 暂停；问号显示操作说明。

视高 1.6 米。自由行走时家具和墙体具有平面碰撞限制；角落速达为快速镜头转场，不再提供物品导览面板。

## 布局依据

以最新俯视示意图为布局依据：图下方为餐厅入口侧，上方为客厅。餐厅仍保留餐边柜、鞋柜、餐桌、装饰窗、油画和时钟。客厅两张沙发都面向茶几；绿色书桌和阳台开口旁墙面上朝向书桌的挂画参照实景照片与用户标注布置，阳台侧为三人沙发，餐厅侧为双人沙发。书桌上方没有额外拱门装饰，沙发坐垫没有黄色板面，也没有绿色盆栽。餐客厅平面长宽各乘以 √2，面积各为原来的两倍，家具本身保持原尺寸。扩大后的房间是观览比例调整，不对应原户型标注的施工尺寸。

## 餐桌处理与限制

现有餐桌模型都混有残缺椅子，因此桌架、四条桌腿、格纹桌布和藏蓝裙边由 Three.js 重建。保留 `餐桌_独立彩色.glb` 内部可分离的桌面摆件几何，裁去外部椅子。没有把旧餐桌椅组合直接放入场景，也没有创建新的 Hyper3D 生成任务。桌面摆件仍保留生成资产原有的简化细节。

所有独立家具按单一比例缩放，不再分别拉伸 XYZ。墙体、顶面、踢脚线、陶土角花瓷砖由 Three.js 创建。瓷砖与布纹为程序纹理。`index.previous.html` 保存旧页面，`asset-review.html` 是资产外观对照页。源码为 `index.html`、`style.css`、`room.js`。





## 尺寸维护
`room.js` 中的 `ROOM`、`LEFT`、`RIGHT`、`ENTRY`、`FRONT` 保留原始户型坐标，`SPACE=Math.SQRT2` 把平面面积扩大两倍。`living.js` 管理客厅家具；新增房间可继续沿用相同坐标变换。


## 钟面与假窗（clock-window-7）
钟面朝向餐边柜中心，由模型实际位置计算水平朝向。假窗宽高等比例缩小 20%，面积减少约 36%；保留原中心高度、餐桌上方位置及贴墙关系。
