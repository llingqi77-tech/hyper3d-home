# 主卧外阳台

独立 Three.js 网页，由主卧外阳台照片和用户补充描述重建。照片确定的右侧区域包括紫花布罩顶开式洗衣机、带浅紫色滤篮的紫色水桶、三层竹木花架、绿萝、灰花盆和扫帚；左侧未入镜的洗衣台、水龙头、肥皂盒与木搓衣板按描述补建。

阳台暂按现有主卧门洞宽 3.10 米、进深 1.65 米、高 2.72 米估算。局部坐标 +Z 朝室外；出门后的右侧为局部 -X，左侧为 +X。它与主卧使用同一套阳台场景和八件 GLB 模型，主卧家具布局不受影响。

运行 `npm run models` 导出 `public/assets/` 下的八件独立 GLB。紫花布纹与竹木纹由代码生成并嵌入相应模型，模型来自本地程序建模，不是 Hyper3D 服务生成。`npm run build` 输出 `dist/`。依赖复用仓库厨房项目的 Three.js 与 Vite，无需另装。

从仓库根目录启动 `python -m http.server 8765 --bind 127.0.0.1`，打开 <http://127.0.0.1:8765/主卧阳台漫游/dist/index.html>。开发模式为 `npm run dev`，端口 5190。

页面提供全景、出门向右、左侧洗衣台和俯视四个视角；可以掀开花布罩看洗衣机、开关水流、打开原始照片对照。尺寸用于展示，不作为施工数据。
