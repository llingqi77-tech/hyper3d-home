# 儿童房独立 3D 网页

运行 `npm install`、`npm run dev`，打开 http://127.0.0.1:5188/ 。拖动旋转、滚轮缩放。没有按钮或设置面板；外侧墙面、天花板随视角自动隐藏。

## 布局和尺寸

局部平面图上方为飘窗，入口在下方靠左。左墙为八门原木柜；上下床在右墙下半部；书桌在右上角；吸顶灯在房间顶面中央。

| 项目 | 尺寸（米） | 依据 |
| --- | --- | --- |
| 房间主体 | 3.66 × 3.63；高 2.72 | 平面图横向分段合计、纵向标注；层高估算 |
| 飘窗 | 宽 1.60、进深 0.70；台高 0.72 | 宽和进深沿用户户型图，台高估算 |
| 八门柜 | 沿墙长 3.24、深 0.55、高 2.38 | 布局比例估算；八扇完整竖向门 |
| 原木书桌 | 宽 0.98、深 0.55、高 0.75 | 布局比例估算 |
| 双层床 | 长 2.10、下铺外宽约 1.40、高 1.82 | 照片比例估算；上铺明显窄于下铺 |
| 吸顶灯 | 直径约 0.46、厚约 0.20 | 灯具细节照片，估算 |

家具不是实测扫描。床和灯基于用户照片提取生成；柜子和书桌依据用户布局、原木颜色要求和同类结构参考生成。书桌、柜体未收到正面细节照片，造型为合理重建。

## 材质

浅粉色墙面；地板复制 `客房漫游/dist/app.js` 的固定随机种子、木板纹理算法、色调 `#b89a8d` 和粗糙度 `0.62`。柜、桌、床为自然棕色木材；窗帘顶部为绿色花边、下部为白色方格，带立体褶皱。

## 独立资产和来源

`public/models/` 存放网页使用的独立 GLB，`source-models/` 保留 Hyper3D 原始版本。原始柜体生成结果为四门带抽屉，未满足八门要求；网页改用 `node export-wardrobe.mjs` 导出的精确八门结构，并保留棕色木纹。渐变窗帘由独立参数化网格导出 GLB；`node export-curtains.mjs` 可重建。

`public/references/` 保存布局图、原照片与内置 image_gen 提取图。完整生成提示词、任务 ID 和同类家具参考网页见 `generation-record.json`。

同类结构参考：[MUJI 木书桌](https://www.muji.com/jp/ja/store/cmdty/detail/4550344873939)、[实木衣柜](https://www.woodlandsfurniture.co.uk/Solid-Pine-Wardrobes)。它们仅帮助补足未拍摄的结构，不作为用户家中家具品牌认定。
