# Hyper3D Home

基于住宅照片、户型图和 Hyper3D 资产制作的 Three.js 三维空间项目。

## 文件夹

| 路径 | 内容 |
| --- | --- |
| `餐厅交互/` | 餐厅家具、整屋墙体结构、第一人称与俯瞰交互网页 |
| `餐厅交互/assets/` | 现有 GLB 模型、OBJ 和纹理，包括历史资产版本 |
| `客厅漫游/` | 独立的 Vite / Three.js 客厅漫游项目 |
| 根目录图片 | 户型图、空间照片、家具细节参考 |
| 根目录 Markdown | 模型生成记录、组合说明和项目提示词 |

## 打开餐厅与户型页面

需要 Python 3。在仓库根目录运行：

```sh
python -m http.server 8765 --bind 127.0.0.1 --directory "餐厅交互"
```

打开 <http://127.0.0.1:8765/>。页面依赖联网加载 Three.js，模型来自仓库本地文件。

- **从门外进入**：打开复古木门并步入餐厅。
- **门外 / 室内 / 俯瞰**：切换视角；俯瞰支持拖动平移与滚轮缩放。
- **W/A/S/D 或方向键**：行走；拖动鼠标环顾。
- **E**：开关门；**R**：返回门外；**Esc**：暂停。

Windows 下 `餐厅交互/启动预览.cmd` 为原工作电脑的便捷启动器，其 Python 路径可能需要在其他电脑上调整；上面的标准命令不依赖该路径。

## 打开客厅项目

需要 Node.js 和 npm：

```sh
cd "客厅漫游"
npm ci
npm run dev
```

按终端提示打开本地网址。项目自带的说明位于 `客厅漫游/README.md`。

## 当前成果与范围

餐厅保留桌椅、餐边柜、鞋凳、假窗、油画、挂钟和吊扇。户型部分根据图中明确尺寸和局部比例建立墙体、窗洞、门洞及通道，无天花板；餐厅以外暂留空。客厅与餐厅共用连续的菱形陶土砖材质。

未标注的墙厚、局部尺寸和位置为估算，模型不是施工图。部分旧模型文件名与实际内容不一致，当前页面采用的资产映射以 `餐厅交互/room.js` 为准。餐桌桌体和桌布为程序重建，搭配已有模型中的桌面摆件。

仓库保留参考图和历史源码备份。`node_modules`、构建缓存、运行日志与本机工具状态不纳入版本管理；依赖可由锁文件恢复。
