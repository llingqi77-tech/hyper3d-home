# hyper3d-home

根据住宅照片和户型资料搭建的 Three.js 三维家居项目，包含餐厅交互、客厅第一人称漫游、模型素材和制作记录。

## 项目内容

| 目录或文件 | 内容 |
| --- | --- |
| `客厅漫游/` | 第一人称客厅漫游，支持移动、家具碰撞、四个预设视角、日夜切换及参考照片查看 |
| `餐厅交互/` | 餐厅与房屋场景、素材核对页面、GLB 和 OBJ 模型、历史版本及启动脚本 |
| 根目录图片及户型图 | 家居照片、家具细节及户型参考 |
| 根目录 Markdown 文件 | 3D 模型生成记录、物件说明和场景提示词 |

## 启动客厅漫游

安装 Node.js，在终端执行：

```powershell
cd 客厅漫游
npm ci
npm run dev
```

打开终端显示的本地地址，默认是 `http://127.0.0.1:5173/`。Windows 下也可双击 `客厅漫游/启动客厅漫游.cmd`。

W A S D 移动，鼠标环顾，Shift 加速，Esc 退出自由漫游。也可使用画面中的方向按钮。

## 启动餐厅交互

双击 `餐厅交互/启动预览.cmd`，或按照该目录中的 README 操作。

## 构建与验证

在 `客厅漫游` 目录执行：

```powershell
npm run build
node --test tests/navigation.test.js
```

场景尺寸和照片未覆盖区域包含估算，具体实现及素材情况见各子项目说明。仓库保留原始参考素材和历史版本；依赖、构建缓存、日志和工具内部记录不提交。
