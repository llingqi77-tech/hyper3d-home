# Hyper3D Home

基于住宅照片、户型图和 Hyper3D 资产制作的 Three.js 三维空间项目。

## 文件夹

| 路径 | 内容 |
| --- | --- |
| `全屋漫游/` | 已恢复 10 月 22 日的十区连续住宅场景，支持全屋立体、俯瞰和行走；构建后更新根目录首页 |
| `餐厅交互/` | 餐厅与客厅合并导览：保留餐厅资产，加入客厅、拱门、第一人称与俯瞰交互 |
| `餐厅交互/assets/` | 现有 GLB 模型、OBJ 和纹理，包括历史资产版本 |
| `客厅漫游/` | 独立的 Vite / Three.js 客厅漫游项目 |
| `儿童房漫游/` | 浅粉墙、八门原木柜、上下宽度不同的双层床、书桌、绿色花边白色方格飘窗帘与花玻璃吸顶灯；`npm run dev` 后打开 5188 端口 |
| `主卧漫游/` | 木柜、木床与绿色床品、床头柜、花纹墙、儿童房同款窗帘和四扇玻璃推拉门；全屋首页可直接进入 |

| 根目录图片 | 户型图、空间照片、家具细节参考 |
| 根目录 Markdown | 模型生成记录、组合说明和项目提示词 |

## 打开全屋导览

根目录 `index.html` 现为完整住宅单一 3D 场景，支持全屋立体、正交俯瞰、逐室定位和连续行走。十个区域位于同一坐标系，不再以房间卡片页作为首页；从餐厅可步行抵达全部十个区域。旧导航页保留为 `各区域网页.html`；细节见 `全屋漫游/README.md`。

需要 Python 3。在仓库根目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8765/index.html>，直接进入全屋场景。Windows 可双击根目录的 `启动全屋3D.cmd`。不要用 `file:///` 直接打开三维页面。

旧导航页仍保留餐厅与客厅合并导览及各区域独立入口。独立项目修改后需在对应目录运行 `npm run build`；全屋场景修改后在 `全屋漫游` 运行 `npm run build`，会同时更新根目录入口。

请从仓库根目录启动服务，以便加载根目录中的参考照片。餐厅与客厅合并导览仍需联网加载 Three.js，模型与照片来自仓库本地文件。

### 餐厅与客厅合并导览操作

- **从门外进入**：打开复古木门，自动经过餐厅与拱门，进入客厅。
- **门外 / 室内 / 俯瞰**：切换视角；俯瞰支持拖动平移与滚轮缩放。
- **鼠标**：拖动环顾，点击地面自动绕开家具行走；也可用 W/A/S/D 或方向键。
- **角落速达**：点击地面浅金色圆点，快速移到餐厅或客厅角落；俯瞰时点击房间地面会跳到最近的角落。
- **E**：开关门；**R**：返回门外；**Esc**：暂停。

Windows 下可双击 `餐厅交互/启动预览.cmd`；它会优先使用 `py -3`，否则使用 PATH 中的 `python`。

## 打开客厅项目

需要 Node.js 和 npm：

```sh
cd "客厅漫游"
npm ci
npm run dev
```

按终端提示打开本地网址。项目自带的说明位于 `客厅漫游/README.md`。

## 当前成果与范围

餐厅保留桌椅、餐边柜、鞋凳、假窗、挂钟和吊扇等原有资产；破碎的油画 GLB 改用参考照片中的完整画布。客厅保留电视、双沙发、茶几、书桌、装饰画和吊扇。全屋首页现使用 10 月 22 日按户型相对位置拼接的版本；它为衔接共享墙体对部分房间作了展示缩放，并非施工尺寸。

餐厅独立页本身采用历史放大展示比例；全屋接入时保留该独立页的原尺寸，不再二次缩放。模型不是施工图。部分旧模型文件名与实际内容不一致，餐厅页面采用的资产映射以 `餐厅交互/room.js` 为准。餐桌桌体和桌布为程序重建，搭配已有模型中的桌面摆件。

仓库保留参考图和历史源码备份。`node_modules`、构建缓存、运行日志与本机工具状态不纳入版本管理；依赖可由锁文件恢复。

## 打开客房三维网页

从资源管理器双击 `客房漫游/启动预览.cmd`，或在该目录运行 `node server.mjs`，然后打开 <http://127.0.0.1:5186/>。页面包含可旋转客房、俯视布局、物品说明、夜间灯光和开关门交互；修订后的布局图与清单可从页面直接打开。
