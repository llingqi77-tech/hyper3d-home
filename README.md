# Hyper3D Home

基于住宅照片、户型图和 Hyper3D 资产制作的 Three.js 三维空间项目。

## 文件夹

| 路径 | 内容 |
| --- | --- |
| `餐厅交互/` | 餐厅与客厅合并导览：保留餐厅资产，加入客厅、拱门、第一人称与俯瞰交互 |
| `餐厅交互/assets/` | 现有 GLB 模型、OBJ 和纹理，包括历史资产版本 |
| `客厅漫游/` | 独立的 Vite / Three.js 客厅漫游项目 |
| 根目录图片 | 户型图、空间照片、家具细节参考 |
| 根目录 Markdown | 模型生成记录、组合说明和项目提示词 |

## 打开餐厅与客厅导览

需要 Python 3。在仓库根目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8765/>。仓库根页面会转到合并导览。请从仓库根目录启动服务，以便加载根目录中的客厅照片；Three.js 仍需联网加载，模型与照片来自仓库本地文件。

- **从门外进入**：打开复古木门，自动经过餐厅与拱门，进入客厅。
- **门外 / 室内 / 俯瞰**：切换视角；俯瞰支持拖动平移与滚轮缩放。
- **鼠标**：拖动环顾，点击地面自动绕开家具行走；也可用 W/A/S/D 或方向键。
- **点击家具或「物品导览」**：飞到物品前查看，并显示对应细节说明。
- **E**：开关门；**R**：返回门外；**Esc**：暂停。

Windows 下可双击 `餐厅交互/启动预览.cmd`；它会优先使用 `py -3`，否则使用 PATH 中的 `python`。

## 打开客厅项目

需要 Node.js 和 npm：

```sh
cd "客厅漫游"
npm ci
npm run dev
```

按终端提示打开本地网址。项目自带的说明位于 `客厅漫游/README.md`。

## 当前成果与范围

餐厅保留桌椅、餐边柜、鞋凳、假窗、油画、挂钟和吊扇，使用原有 GLB 资产与贴图。客厅按户型图布置电视、沙发、茶几、桌椅、窗与阳台方向、装饰画和吊扇，以开放拱门接入餐厅。厨房、卫生间和卧室的区域仍作为未来扩展空间保留。

未标注的墙厚、局部尺寸和位置为估算，模型不是施工图。部分旧模型文件名与实际内容不一致，当前页面采用的资产映射以 `餐厅交互/room.js` 为准。餐桌桌体和桌布为程序重建，搭配已有模型中的桌面摆件。

仓库保留参考图和历史源码备份。`node_modules`、构建缓存、运行日志与本机工具状态不纳入版本管理；依赖可由锁文件恢复。
