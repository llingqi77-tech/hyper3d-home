# 归家 · 客厅第一人称漫游

基于提供的四张客厅照片，用 Three.js 搭建的可自由走动的三维空间。包括花布木沙发、茶几、拼花地砖、奶油色墙面、拱形壁龛与绿色书桌、木餐桌椅、餐边柜、窗帘和铁艺吊灯。尺寸及照片未覆盖区域按视觉关系估算，不用于施工。

## 打开

在此目录运行 `npm install`（首次），然后运行 `npm run dev`，打开 http://127.0.0.1:5173 。也可以双击「启动客厅漫游.cmd」。依赖安装后，运行时无需外部 CDN 或图片服务。

## 操作

1. 按住画面拖动环顾；点击「开始自由漫游」后，鼠标直接控制视线，Esc 退出。
2. W A S D 移动，Shift 加速；方向键前进、后退和转向。墙壁和主要家具具有碰撞限制。
3. 底部切换客厅全景、进门、沙发坐姿和书架四个位置。移动时自动从坐姿起身。
4. 右上切换午后与夜晚、查看四张参考照片；顶栏提供帮助和全屏。
5. 手机滑动环顾，长按左下方方向按钮移动。

## 构建与检查

`npm run build` 生成 dist，`npm run preview` 预览构建结果。`node --test tests/navigation.test.js` 检查碰撞和移动逻辑。

## 文件

`src/room.js` 搭建空间与家具，`src/materials.js` 生成木纹、织物与瓷砖贴图，`src/navigation.js` 负责碰撞，`src/main.js` 负责渲染和操作，`src/style.css` 定义界面。参考照片只在本地读取。
