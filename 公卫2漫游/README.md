# 公卫 2 · 3D 漫游

按已确认的公卫 2 布局制作。23 类独立 Hyper3D 物件，包含 21 个新生成的有效模型，以及从公卫 1 复用的马桶和黑色花洒；同款吊灯、杯子、牙刷、盆和毛巾各复用实例。

## 打开网页

双击本目录的 `启动预览.cmd`，然后访问 http://127.0.0.1:5182/ 。也可在本目录执行 `npm run dev`。独立模型查看页是 http://127.0.0.1:5182/models.html 。

本项目沿用相邻 `厨房漫游/node_modules` 中已有的 Vite 和 Three.js 依赖。无需下载在线脚本或访问模型服务即可浏览已保存的网页。不要直接双击 HTML，以免浏览器阻止本地模型加载。

## 浏览

1. 全景、洗手台、淋浴区和俯视按钮切换视角。俯视使用正交投影，可平移和缩放。
2. 拖动旋转、滚轮缩放；点击物件或右侧清单聚焦。
3. 自然光 / 暖灯切换照明，两盏吊灯各有暖黄色光源。
4. 拉上 / 拉开分隔帘，查看干湿分区；照片与布局按钮打开参考图。
5. 设施 / 日用品筛选清单；独立模型页可逐件旋转检查。

## 布局与材质

北为图上方，西为左侧。洗手柜位于西北，入口在西南，马桶在南侧中部；分隔帘右侧为淋浴区，黑色花洒靠北墙，百叶窗在东墙，地漏在淋浴区东南角。墙地面使用同一组棕陶色方砖纹理。

房间展示尺度约 3.4 × 1.9 × 2.65 m，依据草图比例和设备容纳关系估算，并非实测或施工尺寸。未拍到的吊灯灯罩使用简洁造型表达两盏暖黄色光吊灯，不声称完全还原实物。

## 模型与实现

所有可独立选择的物件均加载 Hyper3D GLB。建筑墙地、门洞边界由 Three.js 搭建；实际镜面反射、玻璃透明材质、光源和帘子开合由网页补充。没有用程序几何占位替代缺失模型；加载失败会在清单提示。

- `public/assets/`：网页使用的贴图优化版 GLB。
- `source-models/`：下载的原始 GLB，保留原始几何和高分辨率纹理。
- `public/references/`：照片、确认布局、内置 imagegen 生成的独立参考图。
- `src/assets.js`：当前采用的模型、尺寸、位置、朝向及复用实例。
- `模型生成记录.md` 与 `model-generation-latest.json`：生成来源、提示词及当前采用状态。

台盆旧版误带龙头、窗户旧版样式不符，均被修正版替代。旧文件保留用于追溯，当前网页不加载它们。模型贴图按物件大小缩至 512 或 1024 像素；原始几何未简化。个别生成模型作了材质校色，毛巾裁除了生成时多带的挂架。

## 构建与检查

在本目录执行 `npm run build`，产物位于 `dist/`，可由任何静态 HTTP 服务托管。`npm run preview` 在 http://127.0.0.1:4182/ 查看构建产物。

`qa/final-report.json` 保存浏览器检查结果；`qa/final-*.png` 保存桌面、手机、四个视角及暖灯和帘子状态截图。`tools/check-final.cjs` 使用本机已安装的 Chrome 与工作区 Playwright，验证模型全加载、无脚本错误、视角、灯光、帘子、参考图、筛选和移动端溢出。
