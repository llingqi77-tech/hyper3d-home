# 主卧 · 木色与花影

独立的 Three.js 主卧网页。房间尺寸为横向长 5.08 米、纵向宽 3.25 米。木柜、木床、床头柜、四扇玻璃推拉门、书桌和木门由 `src/assets.js` 建模并分别导出 GLB；吊灯复用公卫 2 模型；窗帘直接复制儿童房正在使用的 `public/models/curtains.glb`，保留白色格纹帘布、绿色花边、花叶图案和双面材质。窗帘只按主卧门洞调整整体尺寸，不重新配色。模型并非 Hyper3D 生成。

衣柜的四扇门朝右侧的床，衣柜沿左墙纵向摆放，包围盒同时贴紧左墙和挂灯的北侧后墙。两张床头柜仍在床头两侧，均不与衣柜重叠。窗帘与玻璃门在右墙，木门在左下，书桌在右下。窗帘使用独立文件名 `children-curtains.glb`，避免继续读取旧杏色窗帘的缓存。

衣柜纵向长度按床的实际包围盒自动匹配，床头、床尾两端对齐；床与两只床头柜整体靠向衣柜，直到左床头柜台面边缘接触柜门实体表面，吊灯同步对齐。

在仓库根目录双击 `启动全屋3D.cmd`，打开 <http://127.0.0.1:8765/index.html>，选择「主卧」。单独开发时可在本目录运行 `npm run dev`，访问 <http://127.0.0.1:5189/>。修改资产几何后运行 `npm run models`；修改网页后运行 `npm run build`。全屋首页打开构建版 `dist/index.html`。

鼠标拖动旋转、滚轮缩放；可切换门口、床侧、阳台方向视角；可点亮两盏床头灯、开合窗帘、推开两扇内侧玻璃门。房间参考横向长 5.08 米、纵向宽 3.25 米为估算，家具与门窗只作展示，不作为施工尺寸。阳台复用 `../主卧阳台漫游/src/balcony.js` 完整场景与其构建目录中的八件模型；先构建阳台，再构建主卧。主卧上方「进入阳台」可打开独立网页，阳台视角会自动拉开窗帘、推开玻璃门。
