# 三门交汇区

主卧、儿童房、公卫 1 之间的独立 3D 场景。页面只有三维画面，鼠标拖动旋转、滚轮缩放；不含按钮或设置面板。转到外侧时自动隐藏遮挡视线的墙面和吊顶。

## 启动

```powershell
npm install
npm run dev
```

打开 http://127.0.0.1:5187/ 。`npm run build` 输出静态网页至 dist。

## 布局与尺寸

面向儿童房门：主卧门在左侧，公卫 1 门在右侧。绿色柜子及较高的村庄花田画在右墙、两处门洞之间；另一幅画在儿童房门左侧；玻璃吊灯位于上方中央。

| 项目 | 宽 × 深 × 高（厘米） |
| --- | --- |
| 区域房壳 | 255 × 210 × 272 |
| 绿色柜子包围尺寸上限 | 96 × 38 × 109 |
| 吊灯含吊线包围尺寸上限 | 34 × 34 × 65 |
| 儿童房门左侧画 | 40 × 3.5 × 45 |
| 柜子上方画 | 43 × 3.5 × 57 |

以上为照片比例估计，不是现场测量值。三门交汇区用局部坐标搭建；门后只表现短段过渡空间，不包含相邻房间内部。柜子顶部杂物未建模。画面原图分辨率有限，独立画作细节为依据原图的重建。

## 文件

- `public/assets/`：网页使用的四个独立 GLB 模型。
- `source-models/`：Hyper3D 原始 GLB，保留原始尺度。
- `public/references/`：两张原始照片及四张单件提取参考图。
- `generation-record.json`：内置 image_gen 提取提示词、Hyper3D 生成任务 ID。
- `src/main.js`：模型摆放和归一化尺寸；`src/architecture.js`：门洞、墙面、木吊顶和地面。
