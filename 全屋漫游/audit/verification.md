# 全屋场景验收 · 2026-10-23

入口为 `http://127.0.0.1:8765/index.html`。原页面和打包后全屋场景的逐项报告见 `integrated-parity.json`；导航实测见 `runtime-navigation.json`。

1. **结构**：页面只有一个 WebGL canvas；十个原尺寸空间共用同一坐标系和全屋画布，空间清单定位不切换网页。
2. **平面**：`npm test` 检查十个原尺寸房间互不重叠，新增走廊在平面上相连；独立页尺寸优先，不拉伸房间或缩短柜子。
3. **逐项保真**：`npm run test:parity` 检查几何缓冲区、材质与纹理像素、房内相对矩阵、灯光、环境参数及刚性变换；旧版客厅按餐厅原页客厅部分的子集核对。主卧门和阳台推拉门在核对时先恢复原页关闭状态，随后重新打开供全屋通行。厨房石纹采用稳定随机序列。
4. **通行**：浏览器实际碰撞网格验证，从餐厅到十个区域均存在连续路径；主卧木门与阳台推拉门在全屋模式下保持开启。记录在 `runtime-navigation.json`。
5. **画面**：已核对全屋立体、完整正交俯瞰及房间内视角。餐厅附带的旧客厅只显示一次；主卧附带的阳台环境与独立阳台去重。
