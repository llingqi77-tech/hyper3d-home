# 公卫 1 三维漫游

独立的公卫 1 交互网页。房间按户型约 1.42 × 1.70 m 建模，南侧保持开放视角；入口在东南角，约 64 cm 宽并向内开。浴室柜和马桶在西侧，淋浴头固定在东墙并朝向马桶。

## 启动

在本目录独立安装 Three.js 0.170 与 Vite 6.4.3，然后启动。

```powershell
npm install
npm run dev
```

打开 `http://127.0.0.1:5181/`。视角支持拖拽、缩放、场景预设、自然光/暖灯切换、物件定位和参考照片查看。

## 模型状态

- 已接入的 Hyper3D 单体模型：黄色格栅柜、蓝白台盆、双头壁灯、马桶、黑色顶喷与手持花洒，均位于 `public/assets/`。
- 其他物件先由场景几何体补齐；如果 Hyper3D 模型缺失，网页会保留可见替代模型，待单体模型完成后无刷新替换。
- 建筑瓷砖、窗框、毛巾架、置物架、地漏和门扇由 Three.js 生成。

参考图：工作区根目录的 `公卫1.jpg`、`公卫1的洗手台.jpg`、`公卫1洗手台上的灯.jpg`。

参考照片仅保存在本地，未上传公开仓库；缺少照片不影响三维漫游。`npm run build` 输出静态网页到 `dist/`。独立模型预览入口为 `/model-check.html`。上传仓库不等于部署 GitHub Pages。
